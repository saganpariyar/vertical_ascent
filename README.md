# Vertical Ascent (Shaft Hoist)

A 2D co-op physics puzzle-action Flutter game where the **Light** climber launches and wall-kicks up narrow vertical shafts to anchor high overhead, hauling the **Heavy** companion upward like an elevator.

## Features
- **6 Progressive Vertical Shaft Levels** with wall-kick chimneys, timed steam jets, weight-activated hatches, and collectible Energy Cores.
- **Customization Studio (4 Options Per Selection):**
  - 4 Light Climber Profiles, 4 Heavy Payload Profiles, 4 Shaft Backgrounds (`Geothermal Mine`, `Cyber Reactor`, `Pagoda Spire`, `Orbital Elevator`), 4 Hoist Cable Styles, and 4 Pilot Emblem Badges.
- **Solo Swap & 2P Local Split Controls** + Keyboard (`WASD` / `Arrow Keys` / `Space` / `Tab`).

## Run
Double-click `run_app.bat` or run:
```bash
flutter run -d chrome
```
